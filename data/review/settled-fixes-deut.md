# Fixes to the settled Exodus and Numbers, found while making Deuteronomy

Found 2026-11-18 by Deuteronomy's readers, proofreaders and names reader (`deut1-34-stages3-5.md` §"Found in the
settled text"). Settled chapters are never rewritten by code except to apply accepted proposals: these are applied
as accepted, `data/gold/` rebuilt.

**Decision:** accept (Nathan, 2026-11-18: "Fix … the problems in Exodus and Numbers")

1. **Exod 12:15, 12:18, 12:20, 13:7** *fermentātis* → *fermentātīs*: the ablative plural of *fermentātus* (*nōn
   fermentātīs pānibus vēscēminī*); Gaffiot fermentātus; Deuteronomy's 16:3, 16:8 *fermentātīs* (reader 5).
    **Apply:** `Exod.12.15` la: `nōn fermentātis pānibus` → `nōn fermentātīs pānibus`
    **Apply:** `Exod.12.18` la: `nōn fermentātis:` → `nōn fermentātīs:`
    **Apply:** `Exod.12.20` la: `nōn fermentātis vēscēminī` → `nōn fermentātīs vēscēminī`
    **Apply:** `Exod.13.7` la: `nōn fermentātis vīvētur` → `nōn fermentātīs vīvētur`
2. **Num 21:13, 22:1, 32:19, 32:32, 34:15, 35:14** *cīs* → *cis*: Gaffiot cĭs, Wiktionary and Macronizer *cis*; the
   preposition is short in Deuteronomy (1:1, 1:5, 4:41, 4:45) and in *cisjordānīnus* (proofreader 1, names reader).
    **Apply:** `Num.21.13` la: `posuērunt cīs Arnōnem` → `posuērunt cis Arnōnem`
    **Apply:** `Num.22.1` la: `Mōabīticō, cīs Jordānem` → `Mōabīticō, cis Jordānem`
    **Apply:** `Num.32.19` la: `obvēnerit cīs Jordānem` → `obvēnerit cis Jordānem`
    **Apply:** `Num.32.32` la: `possessiōnem cīs Jordānem` → `possessiōnem cis Jordānem`
    **Apply:** `Num.34.15` la: `cēperant cīs Jordānem` → `cēperant cis Jordānem`
    **Apply:** `Num.35.14` la: `tria cīs Jordānem` → `tria cis Jordānem`
3. **Num 32:8, 34:4** *Gadēsbarnēa* → *Cadēsbarnēa*: one form for Kadesh-barnea (decision 46), as Deuteronomy's
   four (1:2, 1:19, 2:14, 9:23) and the settled *Cadēs* for Kadesh (Hebrew qof, LXX Καδης); the edited text only,
   the printed text keeping 1738's *Gades-* (names reader, hard call 1).
    **Apply:** `Num.32.8` la: `ā Gadēsbarnēā` → `ā Cadēsbarnēā`
    **Apply:** `Num.34.4` la: `ad Gadēsbarnēam` → `ad Cadēsbarnēam`
4. **Num 18:26** *adsignātās* → *assignātās* and **Num 33:54** *adsignāverit* → *assignāverit*: decision 37 (*ad-*
   assimilated; the approved *adsignavit → assignavit*), as the settled text's 11 other *assign-* forms and
   Deuteronomy's 31:7, 32:8.
    **Apply:** `Num.18.26` la: `illīs adsignātās` → `illīs assignātās`
    **Apply:** `Num.33.54` la: `sors locum adsignāverit` → `sors locum assignāverit`

Checked and left: *sōlemn-* (Exod 12:24, Lev 23, Num 10:10, 15:3, 29:39): Gaffiot heads *sollemnis*, short o, but
Wiktionary and Macronizer mark the one-l spelling *sōlemnis*, so it is not a clear slip. *nōlitōte*, which a
proofreader thought was in the settled text, is not there. Outside Exodus and Numbers, still to do: *Seirīs* (Gen
14:6, 36:21, a genitive), Mark 10:1 *trānsjordānīnum* (lower case), Mark 12:29 *Audī Isrāēlīta:* (the vocative's comma).
